# Meeting Analysis Bot (Node.js)

Этот бот для Telegram автоматически транскрибирует аудио и видео сообщения, анализирует их содержание с помощью ИИ (Groq) и создает карточки в Planka.

## Технологии
- Node.js
- Telegraf (Telegram Bot API)
- Groq SDK (Whisper-large-v3 + Llama-3.3-70b-versatile)
- Axios (HTTP-клиент)

## Установка

1. Склонируйте репозиторий.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Создайте файл `.env` на основе `.env.example` и заполните необходимые переменные:
   - `TELEGRAM_BOT_TOKEN`: Токен вашего бота от @BotFather.
   - `GROQ_API_KEY`: API ключ от Groq.
   - `PLANKA_API_URL`: URL эндпоинта вашего бэкенда Planka.

## Запуск

### Обычный запуск:
```bash
node index.js
```

### Запуск в режиме разработки (рекомендуется использовать nodemon):
```bash
npm install -g nodemon
nodemon index.js
```

## Как использовать
1. Начните чат с ботом.
2. Отправьте голосовое сообщение, аудиофайл или видеофайл (до 25 МБ).
3. Бот расшифрует аудио, составит краткое резюме, список задач и ключевых решений.
4. Результат будет отправлен вам в чат и автоматически создан в Planka.

## Ограничения
- Максимальный размер файла: 25 МБ (ограничение Groq API).
